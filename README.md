# FNN Studio Website

Sistem web manajemen projek berbasis Laravel untuk mengelola klien, kontak, paket layanan, projek, PO, kru/freelancer, deliverable, revisi, kendala, dan pembayaran pada FNN Studio.

## Stack

- **Database**: PostgreSQL
- **Backend**: Laravel (PHP) menggunakan Eloquent ORM, Form Requests, Policies, dan Service Classes.
- **Frontend**: Blade Templates, Tailwind CSS, dan JavaScript
- **Autentikasi & Otorisasi**: Laravel Auth dan Laravel Policies untuk kontrol akses
